# Data and code availability

The current working manuscript is *Structural context and women’s endorsement of justifications for intimate partner violence*. Its public repository is [Harmful-social-norms-ipv-predictability](https://github.com/Caroline070590/Harmful-social-norms-ipv-predictability).

The current `revision_2026/` workflow supplies official aggregate inputs, public derived summaries, analysis code and explicitly scoped reproduction commands. It distinguishes reproduction of aggregate predictions/summaries from refitting every model from original source records. See [CURRENT_ANALYSES.md](CURRENT_ANALYSES.md) and the relevant module documentation. The package does not claim that all original-source fits can be reproduced from the included tables alone.

The historical top-level repository already includes the Kaggle-distributed attitude compilation, processed aggregate tables, earlier notebooks/scripts, external indicators and earlier outputs. These are historical aggregate data, not respondent microdata. Their existing distribution is distinguished from the current provider-retrieval policy for new source inputs; historical sharing is not represented as if it had never occurred.

The revised national analysis uses official estimates and survey metadata from the [DHS Program API](https://api.dhsprogram.com/) and documented external survey reports/inventories. UNDP and V-Dem/Our World in Data provide structural indicators. Exact source releases, retrieval information and model inputs are identified in the accompanying analysis documentation.

Separate individual-level analyses use releases supplied by INEI (ENDES), Afrobarometer, the Global Flourishing Study and UN Women under their respective access and reuse conditions. New public code/results additions exclude respondent records and private fitted artifacts derived from them. Refitting those models requires original provider files, source-specific instructions, expected inputs and the appropriate environment. Participants are not linked across studies or to national aggregate estimates.

The final manuscript availability statement must describe the exact files distributed at the submitted repository commit, including the existing historical input. Public access alone does not authorize redistribution of third-party materials or establish an ethics exemption.

The [earlier medRxiv preprint](https://www.medrxiv.org/content/10.64898/2026.01.25.26344795v1.full) has a different title and analytical scope. Associated earlier files remain historical materials rather than the current focused manuscript.
