# reported ipv

Current manuscript: Supplementary Section S31.

Public reported preceding-year IPV classification score/calibration arithmetic, saved conditional contrasts and fold diagnostics. No participant-level fitting or prospective violence prediction.

Portable command, from this folder:

```text
python replay_aggregates.py --check
```

This compact module preserves byte-identical original scientific code, configuration/protocol and allowlisted public aggregate tables from the previously checked public archive. Original workflow notes and Results are historical; the current BMC manuscript and this scope statement govern the present interpretation. Figures, private records, fitted respondent states, posterior blocks and acquisition reports are omitted. The original producer fitting code documents the model but requires its provider-acquired inputs and upstream repository paths; it is not a self-contained raw-source/model-training release. Some historical Results links therefore point to assets intentionally excluded from this compact checkout.
